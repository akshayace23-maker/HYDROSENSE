The gap today

Without HydroSense

A citizen notices a problem → takes a photo → doesn't know where to report it → files a general complaint → it gets routed around → the citizen waits → it's unclear whether the water body ever improved.

With HydroSense

Observe → Report → Locate → Confirm → Authority action → Follow-up → Before/after evidence, all tied to a Report ID the citizen can track from submission to resolution.

Important principle

AI assists. It never decides.

HydroSense can flag possible visible indicators in a photo and suggest a follow-up question — but official verification always requires authority review and, where needed, field inspection. Citizen observation, AI-assisted assessment, authority inspection and laboratory measurement are always shown separately, never blended.
